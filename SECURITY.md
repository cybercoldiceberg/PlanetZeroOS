# Security Policy

## Supported Versions
Only the latest Level-0 alpha release is currently supported for security reporting:

| Version | Supported |
| :--- | :--- |
| `v0.1.0-Level-0` | :white_check_mark: |

## Reporting a Vulnerability
PlanetZero OS is an independent, bare-metal operating system built with strict privilege ring separation (Ring-0 through Ring-3). 

If you discover a privilege escalation, memory corruption, bootloader bypass, or shell vulnerability:
1. **Do not open a public GitHub Issue.**
2. Use GitHub's **Private Vulnerability Reporting** feature under the **Security** tab to submit a Proof of Concept (PoC) and reproduction steps.
